# Wanderers HD

A small retro pixel-art side-scrolling platformer built with Phaser 3 and TypeScript.

## Features

- 960x540 retro presentation with pixel-art rendering
- Side-scrolling platforming gameplay
- Enemies that patrol the terrain
- Collectible relics to complete the run
- Title screen and basic menu flow
- Sound effects generated in-browser with Web Audio

## Controls

- A / D or Left / Right: Move
- W or Space: Jump
- M: Toggle music/sound

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Production build

```bash
npm run build
```

## Notes

This project intentionally uses generated placeholder art and procedural audio so it runs without external asset files.
